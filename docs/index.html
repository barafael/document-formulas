document_formulas

KaTeX-rendered math formulas in your rustdoc, extracted from function bodies. Each documented function carries a Formulas section in the API docs that prints its arithmetic as typeset equations instead of code, so you can read the maths without reading Rust.

CrateWhat lives there
document_formulas The #[formula_doc] attribute itself
kalman Scalar 1D Kalman filter — predict/update equations (Kalman1D)
projectile Ballistics closed forms — range, apex, trajectory
finance Compound interest and loan amortization

Deployed on every push to barafael/document-formulas. Formulas render via KaTeX from a CDN, so the pages need network access.
